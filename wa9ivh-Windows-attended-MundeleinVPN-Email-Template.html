Subject: Setup Instructions for your MundeleinVPN Connection (Windows Manual Setup)

Hello,

To access the MundeleinVPN securely from your Windows 11 computer, please follow these step-by-step instructions to manually create the connection in Settings.

Step 1: Create the VPN Connection

  1. Open Settings > Network & internet > VPN.
  2. Click Add VPN.
  3. VPN provider = Windows (built-in).
  4. Connection name = MundeleinVPN.
  5. Server name or address = MundeleinVPN.ddns.net.
  6. VPN type = L2TP/IPsec with pre-shared key.
  7. Pre-shared key = vpn.
  8. Type of sign-in info = User name and password.
  9. User name = wa9ivh.
  10. Password = wa9ivh344.
  11. Click Save.

Step 2: How to Connect and Disconnect

To connect, click the network icon in the taskbar, click VPN, select MundeleinVPN, then click Connect.

To disconnect, click the network icon, click VPN, select MundeleinVPN, then click Disconnect.

Troubleshooting Note

If the connection fails behind a router with NAT, this is commonly caused by NAT-T. An administrator may need to set the AssumeUDPEncapsulationContextOnSendRule registry value to 2 under HKLM\SYSTEM\CurrentControlSet\Services\PolicyAgent, then restart the computer.

Please contact me if you encounter any authentication errors or blockages during setup.
